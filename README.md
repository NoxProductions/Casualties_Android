This is an Android port of **Casualties: Unknown**, with CasMP ( Multiplayer ) built in and upcoming crossplay support with the windows version

## Download and install

1. Get the latest APK from the [releases](https://github.com/NoxProductions/Casualties_Android/releases) page
2. On your phone, allow installing from unknown sources for your browser or file manager
3. Open the APK and install it
4. Launch the game!

## Multiplayer

- CasMP ( Casualties: Multiplayer ) is a crossplay multiplayer mod that brings PC and android players together
### Getting Started
1. Create an account in-game or on website
2. Create a lobby or join an existing one
3. Invite your friends and start playing!


### Crossplay

- Currently CasMP for Windows is still in development, once it is done, a link will be provided bellow

- **Player Interaction:** Interact with other players through the trust system, inventory sharing and the health panel
- **Voice Chat:** Communicate with other players using the built-in voice chat
- **Advanced Dying:** Player deaths are affected by their medical condition and if anyone is near them

### How to chat
**There are two ways you can chat with others:**
1. For chatting: Double press the <img width="32" height="32" alt="chat" src="https://github.com/user-attachments/assets/10b855ac-9447-44d8-bb4e-0d3771cfbe79" /> button
2. For Voice chat: Press and hold the <img width="32" height="32" alt="chat" src="https://github.com/user-attachments/assets/10b855ac-9447-44d8-bb4e-0d3771cfbe79" /> button

**Note:** To use Voice Chat, you need to enable it first
- For both client and host: Settings > Multiplayer > Your Multiplayer Settings > Voice chat

Then the game will ask for your device microphone permission
> This is an Alpha version, it can contain bugs

> Multiplayer requires Android 8.0 or later
## Differences from the PC version

There are no differences anymore, the original shaders have been ported mostly 1:1 with only very tiny differences.
* Performance on lower end phones is pretty good, a Pixel 4a can run it at about 60fps on average in sandbox mode, 50-60fps in WorldGen.

## Compatibility

**Pretty much all Mali/Tensor GPU's are supported**

* Phone brands likely supported: Pixel ( Pixel 6 and newer / Tensor models ), Xiaomi ( Mid-Range & Upper Mid-Range ), Redmi ( Budget & Mid-Range ), Poco ( Select Mid-Range ), Realme ( Budget & Mid-Range ), Oppo ( Mid-Range & Flagship ), Vivo ( Mid-Range & Flagship ), OnePlus ( Mid-Range & Upper Mid-Range ), Samsung ( Galaxy A-series & Select FE ), Motorola ( Budget & Mid-Range ), Tecno ( Budget & Mid-Range ), and Infinix ( Budget & Mid-Range ).
